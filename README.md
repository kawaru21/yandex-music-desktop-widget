# Виджет Яндекс Музыки

## Скачать и запустить

Откройте [последний выпуск](https://github.com/kawaru21/yandex-music-desktop-widget/releases/latest),
скачайте **MusicWidget.exe** в разделе **Assets** и запустите двойным щелчком.
Виджет появится на рабочем столе; настройки доступны через значок в трее.
Архив **Source code (zip)** содержит только исходный код и для простого запуска
не нужен.

## Сборка из исходного кода

Исходный код открыт по лицензии MIT. Проект собирается в Windows 10/11 с
.NET Framework и PowerShell. Для сборки и установки выполните:

```powershell
.\build.ps1
.\install.ps1
```

Скрипт установки помещает приложение в
`%LOCALAPPDATA%\Programs\YandexMusicWidget`, добавляет автозапуск после
входа в Windows, ярлык на рабочем столе и пункт в меню «Пуск».
Повторный запуск установки обновляет виджет.

Запуск: `MusicWidget.exe` или любой из ярлыков. Приложение работает в трее и не создаёт кнопки
на панели задач или карточки в Alt+Tab. Повторный запуск показывает уже
работающий виджет.

В трее ищите круглый фиолетово-оранжевый значок с белой нотой
(при необходимости нажмите стрелку скрытых значков).
Установщик закрепляет значок в видимой области трея. После входа в Windows
виджет запускается скрытым; значок остаётся доступным для открытия.

- Левая кнопка по значку — показать виджет.
- Правая кнопка — показать / скрыть, настройки, открыть Музыку, закрыть окно.
- В настройках доступны «Живой фон», «Поверх всех окон» и сброс положения.
- Там же выбираются скорость движения цвета и размер виджета.
- Внизу виджета есть полоса громкости только для звука Яндекс Музыки.
  Нажатие в любом месте полосы сразу меняет уровень; зажатую кнопку мыши
  можно вести влево и вправо для плавной регулировки.
- «Закрыть окно» оставляет приложение и значок в трее.
- Закрытие окна также скрывает виджет в трей.
- Виджет можно перетаскивать за фон. Положение и настройки сохраняются.

Фон использует размытую обложку и до восьми её характерных цветов.
Полупрозрачные цветные области плавно перемещаются и смешиваются.
При смене песни палитра плавно обновляется. Анимация останавливается,
когда виджет скрыт. Монохромная обложка остаётся монохромной.

Музыкальные данные поступают из системной медиасессии установленного
приложения Яндекс Музыки. Вход в аккаунт и дополнительные ключи не нужны.

## Сборка и проверка

`./build.ps1` использует установленный в Windows .NET Framework.
`MusicWidget.exe --self-test` проверяет расчёты времени, выделение палитры
и движение цветовых областей.
`MusicWidget.exe --verify-ui` запускает проверку фоновой анимации,
скрытия и показа через обработчики меню трея, отсутствия кнопки на панели
задач и режима рабочего стола. Выполняется при закрытом основном экземпляре.

Настройки и диагностические файлы: `%LOCALAPPDATA%\YandexMusicWidget`.
`widget-frame-1.png` и `widget-frame-2.png` — рендеры реального содержимого
окна, снятые при проверке с интервалом 2,4 секунды.
